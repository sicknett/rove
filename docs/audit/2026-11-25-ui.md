# Audit 2026-11-25 — navigation, Home, browse, collections, settings, shared UI

Code-read audit. Each line: where, what the user sees, the fix. Paths are under `ui/src/`.

Status after the fix pass of 2026-11-25: `[fixed]`, `[partly: what is left]` or `[open: why]` in front of each item. Fixed means the code was changed and type-checks, with unit tests where the logic can be tested (navigation, collection cleaning, layout reset, HTTP retries, the server list); the rest was checked in the dev build in a browser, not in the packaged app.

## High
- [fixed] U1 `ui/controls.tsx:195-197` (with `:153-154`; `Menu` at `:270-272`) — long dropdowns cannot be scrolled: the list snaps back to the selected item. Fix: focus the selected option only when it opens; ignore scroll events from inside the popover.
- [fixed] U3 `screens/home/Home.tsx` (empty state) — Home shows only "Add your addons" whenever there are zero addons, even with a media server or collections. Fix: show it only when there are no rows besides Continue Watching.
- [fixed] U4 `ui/controls.tsx:170-175,362-372` — Escape in a dropdown inside a dialog closes the whole dialog (unsaved folder edits lost). Fix: Dialog/Sheet ignore Escape while a popover is open.
- [fixed] U5 `screens/browse.tsx:191-198` — Search's debounced `replace()` can turn another screen into Search. Fix: only replace if the Search entry is still current.
- [fixed] U6 `screens/browse.tsx:117`, `media/Grid.tsx:67-69`, `media/Row.tsx:51-58` — a failed "load more" wipes the Discover grid, or retries forever on catalog pages, collection grids and Home rows. Fix: branch on `isFetchNextPageError`, keep items, inline Retry, stop auto-loading while errored.
- [fixed] U7 `data/sources.ts:47-52` — collection folders page forever when an addon ignores `skip`. Fix: copy the "nothing new" guard from `useCatalog`.
- [fixed] U8 `screens/home/Home.tsx` (CatalogRow), `screens/browse.tsx:145,293,442` — addon failures look like empty content ("Nothing here", "check the spelling", "needs a TMDB key"). Fix: error state with Retry.
- [fixed: timeouts are not retried in `lib/http.ts` and the query client no longer retries on top] U9 `lib/http.ts:42-71`, `App.tsx:34` — a hung addon shows skeletons for ~2.5 minutes (timeouts retried in two layers). Fix: do not retry timeouts, or `retry: 0` for those queries.
- [fixed] U10 `meta/tmdb.ts:28-37`, `data/hooks.ts:46-67`, `screens/settings/accounts.tsx:208-216` — TMDB errors cached as "no data" for a day; any string accepted as a key. Fix: throw on failure; validate the key before saving; key fingerprint in query keys.
- [fixed] U11 `screens/settings/home.tsx`, `state/homeLayout.ts` (`reset`), `screens/home/Home.tsx` — "Reset layout" empties Home until a fresh mount. Fix: rebuild rows after reset.
- [fixed] U12 `screens/settings/addons.tsx:45`, `screens/Onboarding.tsx:56`, `addons/store.ts:74-83` — Enter twice installs an addon twice. Fix: guard on busy; re-check after the manifest fetch.
